# 💊 Online Medicine Quality Monitoring System

## 📌 Project Overview
The **Online Medicine Quality Monitoring System** is a web-based application designed to monitor and manage medicine quality efficiently. The system helps users identify genuine medicines, track expiry dates, and reduce the circulation of fake or expired medicines.

This project provides a secure and user-friendly platform for managing medicine records digitally.

---

# 🚀 Features

## 👤 User Features
- 🔍 Search medicines
- 💊 View medicine details
- 📅 Check expiry information
- ✅ Verify medicine quality status

## 🛠️ Admin Features
- ➕ Add new medicines
- ✏️ Update medicine records
- ❌ Delete medicine information
- 📊 Monitor quality reports

# ⚡ Installation Steps

## 1️⃣ Clone Repository

```bash
git clone https://github.com/dishapatidar165/medqual.git
```

---

## 2️⃣ Open Project Folder

```bash
cd medqual
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r backend/requirements.txt
```

---

## 4️⃣ Setup Database

- Open MySQL
- Create a database
- Import `schema.sql`

---

## 5️⃣ Run Application

```bash
python backend/app.py
```
